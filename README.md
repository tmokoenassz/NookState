# NookState

A simple NookState Platform for Auto scaling.

NookState is built to be simple and practical, focusing on doing one thing well.

**Why NookState?**

## Technology Stack

- python
- Standard library, minimal dependencies
- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/minhokingkim/NookState.git`
2. `cd NookState`
3. Install in editable mode: `pip install -e .`

## Configuration

NookState is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
